# Mi lista de tareas
Aplicación de gestión de tareas.

# Tecnologías
- HTML5
- CSS3
- Bootstrap
- JavaScript Vanilla
- JSON server
- Axios
- GitHub

# Cómo ejecutar

1. Clonar el repositorio
2. Abrir la terminal en la carpeta del proyecto
3. Ejecutar el servidor: `npx json-server --watch db.json --port 3000`
4. Abrir index.html con un servidor local (Live Server, http-server, etc.)

# Funcionalidades
- Listar tareas
- Agregar tareas
- Editar tareas
- Eliminar tareas
- Marcar las tareas como completas
- Filtrar por tareas completas y pendientes
